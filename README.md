# وَرَقي — مفكرتك الرقمية

تطبيق ملاحظات عربي متجاوب يعمل على الهاتف والتابلت والكمبيوتر.

## التشغيل في VS Code
1. فك ضغط الملف.
2. افتح المجلد في VS Code.
3. شغّل `index.html` باستخدام إضافة Live Server (موصى بها).
4. افتح الرابط المحلي الذي يعرضه Live Server.

> لتجربة التثبيت والعمل دون اتصال، استخدم HTTPS أو localhost. فتح الملف مباشرة `file://` لا يفعّل Service Worker.

## المميزات
- إنشاء الملاحظات وتصنيفها في الدراسة وأفكاري واليوميات.
- الكتابة بلوحة المفاتيح والرسم باللمس أو القلم على مساحة الرسم.
- قلم، تمييز، ممحاة، ألوان، أحجام، تراجع ومسح الرسم.
- قوالب: ورقة بيضاء، مسطرة، مربعات، نقط، مخطط أسبوعي، محضر اجتماع، ملخص درس، ودفتر أفكار.
- إضافة صور وملفات PDF كمرفقات.
- تصدير الملاحظة إلى PDF عبر نافذة الطباعة: اختر Save as PDF / حفظ كملف PDF.
- بحث، مظهر ليلي، حفظ تلقائي محلي، وتصدير/استيراد نسخة احتياطية JSON.
- PWA: يمكن تثبيته على الشاشة الرئيسية من قائمة المتصفح عند تشغيله على HTTPS أو localhost.

## التثبيت على iPhone
1. ارفع المجلد على استضافة HTTPS (أو شغّله محلياً للاختبار).
2. افتح الرابط في Safari.
3. اضغط مشاركة ثم «إضافة إلى الشاشة الرئيسية».

## التثبيت على Android
افتح الرابط في Chrome ثم قائمة ⋮ ثم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

## ملاحظات مهمة
- البيانات تحفظ محلياً في المتصفح على نفس الجهاز؛ لا يوجد حساب أو مزامنة سحابية بين أجهزتك في هذه النسخة.
- ملفات PDF المرفقة تُحفظ داخل بيانات الملاحظة وقد تستهلك مساحة تخزين كبيرة.
- تصدير PDF يعتمد على نافذة الطباعة في المتصفح؛ اختر حفظ كـ PDF.
- الخط العربي يستخدم Google Fonts عند توفر الإنترنت، مع خط نظام بديل عند عدم توفره.

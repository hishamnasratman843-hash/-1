# وَرَقي — مفكرتك الرقمية (الإصدار المحسّن)

دفتر رقمي عربي يعمل على الهاتف والتابلت والكمبيوتر، ويمكن تثبيته كتطبيق PWA.

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `waraqi` في VS Code.
3. شغّل `index.html` باستخدام Live Server.
4. على iPhone افتح رابط HTTPS في Safari ثم مشاركة ← إضافة إلى الشاشة الرئيسية.
   وعلى Android افتح الرابط في Chrome ثم القائمة ← تثبيت التطبيق.

## الجديد في هذا الإصدار
- تكبير وتصغير مباشر بإصبعين على شاشات اللمس.
- تكبير بعجلة الماوس مع Ctrl أو Cmd، مع الاحتفاظ بحدود تكبير مناسبة.
- دفتر متعدد الصفحات: أضف صفحات وانتقل بينها داخل الملاحظة نفسها.
- إعداد قبل البدء لاختيار اسم المجلد ولونه، قالب الورقة ولون خلفيتها.
- قوالب إضافية: أبيض، مسطر، مربعات، نقط، مخطط، كورنيل، نوتة موسيقية، وشبكة هندسية.
- قلم عادي، قلم تمييز، قلم خط عربي/رقعة تجريبي، وفرشاة ناعمة.
- ممحاة يدوية تمسح الجزء الذي تمررها عليه فقط، مع تراجع وإعادة.
- إضافة أشكال أساسية ومساطر، ومرفقات الصور وPDF.
- حفظ تلقائي محلي، بحث، وضع ليلي، واستيراد/تصدير نسخة احتياطية.
- تصدير الصفحة الحالية للطباعة أو الحفظ PDF.

## ملاحظات مهمة
- الرسم يتم على لوحة نقطية؛ الممحاة تمسح المنطقة التي تمررها عليها، وليست ممحاة كائنات منفصلة.
- قلم الخط العربي تأثيره تجريبي وليس محرك تشكيل خطاطي احترافي كامل.
- التكبير بالإصبعين مدعوم داخل مساحة الورقة، والماوس يستخدم Ctrl/Cmd مع عجلة التمرير.
- البيانات محفوظة محليًا في متصفح الجهاز؛ لا توجد مزامنة سحابية تلقائية بين الأجهزة.
- تصدير PDF يعتمد على نافذة الطباعة في المتصفح، اختر Save as PDF.
- لتفعيل التثبيت والعمل دون اتصال استخدم HTTPS أو localhost؛ فتح الملف مباشرة لا يفعّل Service Worker.
